# 格式化解析（Sscanf）

提供 `mr_sscanf` 格式化解析入口，按格式串从字符串中提取整数、字符、字符串与扫描集等字段，常用于命令行参数与文本协议解析。

| 项目   | 说明                                                                                                              |
|--------|-------------------------------------------------------------------------------------------------------------------|
| 功能宏 | `MR_USE_SSCANF`（内置封装）；`MR_USE_SSCANF_STD`（转发标准库）；`MR_USE_SSCANF_3RD`（Kconfig 预留项，当前无实现） |
| 头文件 | `<mrX/libc/mr_sscanf.h>`                                                                                          |
| 依赖   | 工具链 C 库 `vsscanf`（`<stdio.h>`）                                                                              |
| 测试   | `test/libc/sscanf.c`、`test/libc/sscanf_matrix.c`                                                                 |

## 配置

| 配置项              | 类型           | 默认值 | 说明                                               |
|---------------------|----------------|--------|----------------------------------------------------|
| `MR_USE_SSCANF`     | bool（choice） | y      | 使用内置封装（空指针校验后转发工具链 `vsscanf`）   |
| `MR_USE_SSCANF_STD` | bool（choice） | n      | 宏转发标准库 `sscanf`                              |
| `MR_USE_SSCANF_3RD` | bool（choice） | n      | 第三方解析库预留项，当前头文件与源码无对应实现分支 |

## 快速上手

```c
#include <mrX/libc/mr_sscanf.h>

void example(void) {
    int id;
    char name[8];

    /* 限定宽度 %7s 为 8 字节缓冲预留 '\0' */
    if (mr_sscanf("42 hello", "%d %7s", &id, name) == 2) {
        /* id == 42, name == "hello" */
    }
}
```

## 核心机制与约束

- **实现本质与链接依赖**：与自研引擎 `mr_sprintf` 不同，`MR_USE_SSCANF` 模式下的
  `mr_sscanf`（`libc/sscanf.c`）并非手写解析器，而是在校验 `buf`/`fmt` 非空后直接转发至标准库
  `vsscanf`。因此转换能力（`%d`、`%i`、`%u`、`%x`、`%o`、`%c`、`%s`、`%[...]`、`%n`、`%%`
  、宽度与 `*` 赋值抑制）、代码体积以及线程/中断安全性均由工具链 C 库决定，且会引入
  `<stdio.h>` 链接依赖。
- **返回值语义**：成功时返回赋值的字段数（`%n` 不计入）；若第一个字段即匹配失败（如
  `"abc"` 配 `%d`）或格式串为空则返回 `0`；若输入在首次成功赋值前已耗尽（如空输入
  `""`）则返回 `EOF`（常见 C 库为 `-1`）；`buf` 或 `fmt` 为 `MR_NULL` 时封装固定返回
  `-1`。判断完整解析成功应直接比较返回值与期望赋值字段数。
- **常见用法陷阱**：`%c` 不跳过前导空白，需要跳过空白时应写 `" %c"`；`%s` 与
  `%[...]` 扫描集无自动边界检查，必须显式指定最大宽度（缓冲区大小减 1）。

## API 速查

| API                                                    | 说明                                                                           |
|--------------------------------------------------------|--------------------------------------------------------------------------------|
| `int mr_sscanf(const char *buf, const char *fmt, ...)` | 按格式串从 `buf` 解析字段并写入指针参数；`buf` 或 `fmt` 为 `MR_NULL` 返回 `-1` |
